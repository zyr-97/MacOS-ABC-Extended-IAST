ABC Extended - IAST 2.3：安裝說明

以 macOS 自帶的 ABC Extended 為基礎，用 Option 組合鍵直接輸入 IAST 梵語轉寫、
長短音、格律及校勘符號。普通字母、數字、標點與 ABC Extended 相同。
按鍵一覽見「符號速查.txt」，完整逐鍵輸出見「輸出對照.txt」。

⌥ = Option，⇧ = Shift，均同時按住；左右兩側皆可。
→ 表示放開後再按下一組。小寫字母（如 a）表示直接按該鍵。


一、安裝

1. 下載本倉庫（GitHub 頁面 Code → Download ZIP）並解壓縮。
2. 在 Finder 按 ⇧⌘G，輸入 ~/Library/Keyboard Layouts/ 後按 Return。
   若沒有此資料夾，在 ~/Library/ 內新建一個，名為 Keyboard Layouts。
3. 把整個 ABC-Extended-IAST-2.3.bundle 複製進去。
   不要只取出其中的 .keylayout；docs、source、tools 都不用複製。
   不需要管理員權限、Python 或 Ukelele，也沒有常駐程式。
4. 儲存工作，登出再登入（或重新開機）。
5. 加入輸入方式：
   macOS 13 及以後：系統設定 → 鍵盤 → 文字輸入 → 輸入方式「編輯…」→ ＋
   macOS 12 及以前：系統偏好設定 → 鍵盤 → 輸入方式 → ＋
   在「英文」或「其他」分類中選 ABC Extended - IAST 2.3，按「加入」；
   也可以直接在搜尋欄輸入 IAST 找到它。
6. 從選單列的輸入法選單切換到 ABC Extended - IAST 2.3。

【重要】安裝後務必登出帳戶，再重新登入（第 4 步）。macOS 只在登入時載入新的鍵盤布局。
沒有重新登入，列表裡可能找不到本布局，或者系統仍在使用舊版本，⌥逗號 等按鍵打不出
本說明所寫的字符。每次更新或移除後也要這樣做。若仍未出現，請重新開機。

從舊版更新：2.3 是獨立的輸入方式，可與 2.1 並存。複製新 bundle 後需手動加入並選用 2.3；
確認無誤後再移除舊版。如果裝過 2.2，請移除：它的 ⌥逗號／⌥句號 打不出 < >。

為什麼要用 bundle：bundle 內的 Info.plist 把輸入方式語言聲明為英語（TISIntendedLanguage = en），
Word 為新輸入的文字標記語言時可以據此判斷，切換輸入方式時就不會連帶改變校對語言和字體。
只複製 .keylayout 會失去這個標記。


二、基本用法

• IAST 字母：⌥ + 字母 輸入小寫，⌥⇧ + 字母 輸入大寫，例如 ⌥A = ā，⌥⇧A = Ā。
  這些字母鍵只在 Caps Lock 關閉時生效。
• 長音：ā ī ū 可直接按 ⌥A／⌥I／⌥U；其他字母先打字母再按 ⌥4 追加長音符，
  例如 e → ⌥4 = ē，⌥R → ⌥4 = ṝ。已帶長音的 ā 不要再按 ⌥4。
• 兩點：先打字母再按 ⌥Q，例如 a → ⌥Q = ä。⌥⇧Q 是獨立的 ¨，不附著在字母上。
• 重音：⌥E → ⌥A = ā́（前置），或 ⌥A → ⌥⇧E = ā́（追加），兩種皆可。
• 符號之間不會自動加空格；° 可直接寫成 °rakṣita、sva°，不需設為上標。
• ⇧逗號／⇧句號 輸出 ⟨ ⟩；⌥逗號／⌥句號 輸出 < >。


三、安裝後試打

請在「文字編輯」中親手按鍵（複製貼上只能比較字形，驗證不了鍵位）：

  ⌥A ⌥I ⌥U ⌥R ⌥Y ⌥L ⌥M ⌥W ⌥F ⌥H ⌥1 ⌥2   → ā ī ū ṛ r̥ ḷ ṃ ṁ m̐ ḥ ḫ ẖ
  ⌥T ⌥D ⌥N ⌥G ⌥J ⌥Z ⌥S                   → ṭ ḍ ṇ ṅ ñ ś ṣ
  e → ⌥4，o → ⌥4，⌥R → ⌥4，⌥L → ⌥4       → ē ō ṝ ḹ
  ⌥Y → ⌥4 → ⌥⇧E                            → r̥̄́
  a → ⌥Q，⌥⇧Q                              → ä ¨
  ⌥9 ⌥減號 ⌥0                             → ⏑ – ⏓
  ⇧逗號 ⇧句號 ⌥⇧逗號 ⌥⇧句號 ⌥7              → ⟨ ⟩ ⟪ ⟫ °
  ⌥逗號 ⌥句號                              → < >
  試打一句：namaḥ saṃskṛtam am̐a aḫka aẖka

再用右側 Option／Shift 試一次；若出錯，記下輸入方式名稱、按鍵順序、實際輸出、
Caps Lock 狀態、所用應用及字體。


四、Microsoft Word

bundle 的英語標記只是提示：它不會設定 Word 的字體或上標，也不會改動已有文字的語言。

校對語言：選取轉寫段落 → 工具 → 語言 → English (UK 或 US) → 確定。
  若有「自動偵測語言」可取消勾選。想讓新文件沿用，在同一對話框按「預設」。
  混合文件中的漢語、德語段落不要一起標成英語。
字體：格式 → 字體（⌘D）。若分開顯示「西文字體」與「亞洲文字體」，請改西文字體欄位。
  修改正在使用的樣式，而不是一律清除格式，以免抹掉斜體、上標。
缺字或方框：若只有 m̐、r̥̄́、⏑、⏓、⟨ ⟩ 等少數字符顯示異常，是字體缺字或組合符號定位問題，
  需改用支援這些字符的字體；設定語言解決不了。
選單介面語言是另一項設定：系統設定 → 一般 → 語言與地區 → App，為 Word 選 English。


五、常見問題

• 加入輸入方式時找不到：確認 bundle 位於 ~/Library/Keyboard Layouts/ 且名稱完整，
  然後登出再登入；仍不行就重新開機。
• ⌥ + 字母輸出 ®、¥、ƒ 等原版字符：Caps Lock 開著，關掉即可。
• 【重要】快捷鍵衝突：如果按下 ⌥S 時啟動了截圖、搜尋或翻譯等功能，而沒有輸入 ṣ，
  通常是其他軟件（如詞典）佔用了這個全域快捷鍵。請到該軟件的設定中，停用或重新指定相應的
  快捷鍵，再返回 Word 等應用程式輸入。其他 ⌥ 組合鍵如有類似情況，也可按此處理。
  不確定是哪個軟件時，可逐一暫時退出可疑的軟件來確認。
• 長按 a、e 出現的候選字由 macOS 提供，與本布局無關。
• ⌥A 輸出預組字元 ā（U+0101），a → ⌥4 輸出 a + U+0304，兩者在 Unicode 中等價，
  但搜尋或比對時可能被視為不同字串；布局不會替文件做正規化。


六、卸載

先切換到其他輸入方式，在鍵盤設定中移除 ABC Extended - IAST 2.3，
再刪除 ~/Library/Keyboard Layouts/ABC-Extended-IAST-2.3.bundle，登出再登入。


七、重建（一般使用者不需要）

需要 Python 3.8 以上，只用標準庫，不聯網、不改系統：
  python3 tools/build_and_verify.py     由 source/ 重建 bundle 並寫出 verification.json
  python3 tools/generate_reference.py   由 bundle 重新生成 docs/ 兩份對照表、assets/ 鍵盤圖及 README 按鍵表
驗證是對布局檔的逐狀態比對與模擬輸入，不等於 macOS 實機測試。
