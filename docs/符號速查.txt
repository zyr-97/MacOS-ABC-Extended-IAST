本檔由 tools/generate_reference.py 從布局檔生成，所有例子都經模擬輸入驗證。

⌥ = Option，⇧ = Shift，均同時按住；左右兩側皆可。
→ 表示放開後再按下一組。小寫字母（如 a）表示直接按該鍵。
鍵位以 ABC Extended／美式 QWERTY 為準；數字指上排數字鍵。
IAST 字母鍵請關閉 Caps Lock（數字鍵、Q 及符號鍵不受影響）。

四、組合鍵輸入

前置（死鍵）：先按組合鍵，再打字母。
追加（後置）：先打字母，再按組合鍵，中間不按空格。

附加符號            前置     追加          例子
------------------  -------  ------------  ----------------------------------
acute 尖音符        ⌥E       ⌥⇧E           ⌥E → a = á；⌥A → ⌥⇧E = ā́
grave 抑音符        ⌥反引號  ⌥⇧反引號      ⌥反引號 → a = à；⌥A → ⌥⇧反引號 = ā̀
circumflex 揚抑符   ⌥6       ⌥⇧6           ⌥6 → a = â；⌥A → ⌥⇧6 = ā̂
macron 長音符       —        ⌥4（或 ⌥⇧=）  e → ⌥4 = ē；⌥R → ⌥4 = ṝ
diaeresis 兩點      —        ⌥Q            a → ⌥Q = ä；u → ⌥Q = ü
breve 短音符        ⌥B       ⌥⇧B           ⌥B → a = ă；o → ⌥⇧B = ŏ
caron 抑揚符        ⌥V       ⌥⇧V           ⌥V → c = č；a → ⌥⇧V = ǎ
cedilla 下加符      ⌥C       ⌥⇧C           ⌥C → c = ç
ring 上圓圈         ⌥K       ⌥⇧K           ⌥K → a = å
dot below 下點      ⌥X       ⌥⇧X           ⌥X → n = ṇ；e → ⌥⇧X = ẹ
comma below 下逗號  ⌥P       ⌥⇧P           ⌥P → s = ș

可疊加：⌥Y → ⌥4 → ⌥⇧E = r̥̄́；⌥E → ⌥A = ā́；⌥⇧A → ⌥⇧E = Ā́。
已帶長音的 ā 不要再按 ⌥4，否則會疊上第二個長音符。
