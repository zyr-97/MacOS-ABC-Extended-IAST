# ABC Extended - IAST：安装与使用

文件：`ABC Extended - IAST.keylayout`
输入源名称：`ABC Extended - IAST`

这是一个独立的 macOS 自定义键盘布局，无需安装 Ukelele 或其他常驻软件。
以 macOS 15.7.7 自带的 ABC Extended（内部标识 `com.apple.keylayout.USExtended`）实际键盘数据为基础，只替换下表指定的 25 个组合。不会覆盖系统自带的 ABC Extended。

## 安装

1. 下载或复制 `ABC Extended - IAST.keylayout`，保留 `.keylayout` 扩展名，不要改成 `.txt`。
2. 在 Finder 中按 ⇧⌘G（前往文件夹），输入 `~/Library/Keyboard Layouts/` 并回车。这里的 `~` 代表当前用户的个人文件夹。如果该文件夹不存在，先进入 `~/Library/`，新建名为 `Keyboard Layouts` 的文件夹。
3. 将 `.keylayout` 文件复制到该文件夹。不需要管理员权限。
4. 保存正在进行的工作，退出登录后重新登录。
5. 打开「系统设置 → 键盘 → 文本输入 → 编辑」，点击「＋」添加输入源。查找 `ABC Extended - IAST`；自定义布局通常出现在「其他 / Others」分类中。选中后点击「添加」。不同 macOS 版本的分类、按钮名称可能略有差异。
6. 从菜单栏的输入法菜单选择 `ABC Extended - IAST`。如果看不到菜单，在输入源设置中启用「在菜单栏中显示输入法菜单」。

请保留原版 ABC Extended，方便随时切换回来。如果新布局仍未出现，检查文件是否位于上述目录、扩展名是否正确，再重新启动 Mac。

## 使用

关闭 Caps Lock，选择本布局后，按住 ⌥（Option），再按对应字母，即直接输入小写字符。大写同时按住 ⌥⇧（Option + Shift）。左右 Option / Shift 均支持，无需再按空格或第二个字母。

按键位置遵循 ABC Extended / 美式 QWERTY；非美式键帽上的字母位置可能不同。

| 字母键 | ⌥ + 字母 | ⌥⇧ + 字母 |
| --- | --- | --- |
| A | ā | Ā |
| I | ī | Ī |
| U | ū | Ū |
| R | ṛ | Ṛ |
| L | ḷ | Ḷ |
| M | ṁ | 保留原版：组合下钩 U+0328 |
| T | ṭ | Ṭ |
| D | ḍ | Ḍ |
| Z | ś | Ś |
| S | ṣ | Ṣ |
| N | ṇ | Ṇ |
| G | ṅ | Ṅ |
| J | ñ | Ñ |

特别说明：

- ⌥M 输出 `ṁ`（U+1E41，上点），不是 `ṃ`（U+1E43，下点）。
- 没有添加 ⌥⇧M → Ṁ，因为请求中没有该映射。⌥⇧M 仍输出原版的组合下钩 `̨`，它会附着在前面的字符上。
- 指定组合均输出单个预组 Unicode 字符，不是字母加组合附加符号。
- 普通字母、数字、标点，以及未指定的 Option 组合，保留提取自原版的输出和状态转换。例如 ⌥E 后再按 E 仍可输入 `é`。
- 被替换组合原来对应的符号或死键入口将被新字符取代。例如 ⌥A 现在直接输入 `ā`，不再先进入长音符死键状态。需要这些原版入口时，可切回系统 ABC Extended。
- Caps Lock 开启时，以及包含 Command 或 Control 的组合，保留原版行为；本表的自定义组合适用于 Caps Lock 关闭且未按 Command / Control 时。
- 如已有尚未完成的死键输入，再按自定义组合，会先结束此前的死键并输出其附加符号，再输入指定字符。
- 某些应用可能截获 Option 快捷键。可以先在「文本编辑」中验证；如仅某个应用无效，检查该应用的快捷键设置。

## 验证

在「文本编辑」中新建文稿，切换到本布局，关闭 Caps Lock，依次测试下列两行按键：

小写键序列：⌥A、⌥I、⌥U、⌥R、⌥L、⌥M、⌥T、⌥D、⌥Z、⌥S、⌥N、⌥G、⌥J

预期：`āīūṛḷṁṭḍśṣṇṅñ`

大写键序列：⌥⇧A、⌥⇧I、⌥⇧U、⌥⇧R、⌥⇧L、⌥⇧T、⌥⇧D、⌥⇧Z、⌥⇧S、⌥⇧N、⌥⇧G、⌥⇧J

预期：`ĀĪŪṚḶṬḌŚṢṆṄÑ`

生成时已检查：25 项映射、左右修饰键组合、原版 51 个可达状态，以及两组硬件映射中的未改动状态转换；共比对 3,342,336 项转换。结构通过系统键盘布局 DTD 校验（校验副本对 XML 1.1 控制字符引用作等价占位处理）。

未将文件安装到当前用户的输入源，也未完成安装后的实际按键测试；上述检查属于文件结构和原版行为数据的比对。系统快捷键、登录界面和按键长按候选菜单等行为仍由 macOS 及应用管理。

## 卸载

先切换到其他输入源。在系统设置的输入源列表中移除 `ABC Extended - IAST`，再从 `~/Library/Keyboard Layouts/` 删除该 `.keylayout` 文件，退出登录后重新登录。
